# Безопасность DoxaizOS

Лёгкость не означает «снять защиту». DoxaizOS наследует модель безопасности Android и никогда не ослабляет её ради мегабайт.

## 1. Что остаётся нетронутым (обязательно)

| Механизм | Почему | Правило |
|---|---|---|
| SELinux **enforcing** | Изоляция процессов, граница между приложениями | Никогда не переводить в permissive в релизе; permissive допустим только для локальной отладки с `setenforce 0` на userdebug |
| Verified Boot (AVB 2.0) | Образ не подменён | Подпись boot/system/vendor; на релизных устройствах bootloader блокируется после прошивки |
| Verity (dm-verity) | Read-only разделы защищают себя сами | Не отключать |
| Подписи приложений | Play Integrity, обновления | Все APK (и наш prebuilt) подписаны; подмена невозможна |
| Sandboxed app framework | UID, изоляция данных | Не отключать multiuser/isolate |

## 2. Подпись сборки

* Разработка: `userdebug` + `adb root` (только на своём устройстве/Cuttlefish).
* Релиз: `user` + release keys устройства (`build/make/target/product/security/releasekey, platform, shared, media, networkstack, nfc, sdk_sandbox`).
* Ключи никогда не попадают в git (`*.keystore`, `*.pk8`, `*.pem`, `platform.x509.pem` — в `.gitignore`/закрытом хранилище/CI secrets). Репозиторий содержит только конфигурацию, не секреты.

## 3. Подпись лаунчера

Два пути (подробно — [LAUNCHER.md](LAUNCHER.md)):

* **PRESIGNED** (по умолчанию): APK Doxaiz Launcher подписан своим debug/release-ключом разработчика, работает как обычное (не привилегированное) системное приложение, HOME-роль получает. Privileged permissions не выдаются (allowlist пуст) — это безопасно по умолчанию.
* **Platform key**: для привилегированных возможностей; требует сборки APK с platform key **этой** прошивки (ключи генерируются при сборке/хранятся владельцем сборки) и заполненного `privapp-permissions-doxaiz.xml`.

## 4. Поверхность атаки: что мы убрали

* Нет GMS → нет каналов телеметрии Google, нет утечки в рекламные ID, нет `com.google.android.gms` в памяти.
* Нет SetupWizard → меньше кода на этапе первого запуска.
* Нет automotive/TV/game пакетов → меньше кода в образе (и, соответственно, меньше известных уязвимостей из этих компонентов).
* Нет Google Play Store → приложения ставятся пользователем явно (APK/F-Droid); это осознанный компромисс приватности/контроля.

## 5. Приватность

* Нет аналитики, нет крашей на чужой сервер: whatever crash reporting добавите — только по явному согласию.
* Бэкапы лаунчера (уже в самом лаунчере): JSON-раскладка без секретов по умолчанию; «полная копия» — под PIN/биометрию устройства.
* Место для VPN/DNS-over-TLS — настройка пользователя, DoxaizOS не форсит свои DNS.

## 6. Обновления

* База (AOSP/LineageOS) обновляется **еженедельно** апстримом LineageOS; наша задача — регулярно rebase overlay и relеase подписанные OTA.
* Подпись OTA обязательна; механизм A/B (seamless updates) — если SoC/устройство его поддерживает, иначе recovery-заливка.
* План: этап 7 в [ROADMAP.md](ROADMAP.md).

## 7. Проверки безопасности в CI

* `doxaiz-xtask verify` не пропускает в репозиторий ключи/APK (негативные проверки).
* `privapp-permissions-doxaiz.xml` пуст по умолчанию → privileged permissions лаунчеру не выдаются.
* Весь новый код — Rust + ревью; опасные паттерны (C FFI) в DoxaizOS нет.

## 8. Если нашли уязвимость

Не открывайте публичный issue: напишите мейнтейнеру приватно через GitHub Security Advisories репозитория (Security → Report a vulnerability) — шаблон уже в репозитории лаунчера; для DoxaizOS действует та же политика.
